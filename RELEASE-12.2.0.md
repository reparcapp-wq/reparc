# RepArc 12.2.0 — history-based return starting guidance

- Return and exercise-calibration cards now show a matching prior first set, date, load, reps and effort, with a conservative starting weight/rep target when usable history supports it. Covers both tracks, equivalent swaps, Phase 1, Phase 2 calibration and accessories. Normal established SBS percentages and training-max progression remain unchanged.
- Older lower-rep records, missing/near-failure effort and incomplete exposures provide a clearly marked warm-up rehearsal, not a fabricated working weight. Never auto-fill actual reps/RIR, count warm-ups as work or manufacture confidence from an estimate.
- Respect kg/lb, each-side loads, saved equipment choices, bodyweight changes and the reverse direction of assistance. Missing equipment gives a bound rather than an unavailable selectable weight. Stale records, large inconsistent entries and adverse recovery receive explicit reference-only or stop guidance.
- Combine return reductions once and use the same finalized number for the card and new saved recommendation metadata. A recent protected exposure that met today's sets/reps/effort can repeat its already-reduced weight rather than being discounted on every session. A new return period or harder effort does not qualify for that exception.
- Protected next-set guidance holds or reduces the weight actually used; reaching the intended four-reps-left return target does not trigger an increase. Assisted-exercise difficulty changes use the correct direction and require a bounded effective-resistance step for increases.
- Existing recorded sets, snapshots, training maxes, program position, return counts and recovery promotion rules are preserved. No migration, new data collection or consent changes. New recommendations use `12.2.0-policy5`.
